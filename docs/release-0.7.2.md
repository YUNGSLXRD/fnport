### Исправлено в Windows

- WARP сразу начинает искать выход. Раньше медленный DNS для сервисов Epic мог задержать подключение на несколько минут.
- При выборе приложения целиком его DNS-запросы тоже идут через подключение, если Windows сообщает, какой программе принадлежит сокет. Для запросов общей службы DNS действуют правила доменов.
- Пинг до серверов Epic измеряется без ожидания отправки всей серии пакетов. Маяки идут напрямую, даже когда процесс Fortnite выбран для VPN.
- Во вкладке «Подключения» стало понятнее, где пример домена и сколько приложений выбрано.

Для обновления закройте fnport и распакуйте Windows-архив. Изменения этого выпуска относятся к Windows. Пакеты OpenWrt доступны для установки как обычно.
