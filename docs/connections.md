# Подключения

Игровой UDP Fortnite проходит через fnport напрямую. Вход Epic, магазин, загрузки
и Discord можно направить через отдельное подключение: WARP или ваш VPN.
Одновременно используется один выбранный транспорт.

## Windows

1. Распакуйте весь архив и откройте fnport.exe.
2. На вкладке «Подключения» выберите WARP или протокол своего сервера.
3. Для WARP нажмите «Получить ключ». Сохраненный ключ используется повторно.
   Для VLESS вставьте ссылку vless:// или загрузите подписку. Для AmneziaWG
   импортируйте .conf или вставьте его содержимое. Другие протоколы принимают
   конфигурацию одного подключения sing-box.
4. Отметьте «Сервисы Epic», «Discord» или оба сервиса. При необходимости выберите
   дополнительные приложения в свернутом разделе.
5. Нажмите «Применить», включите fnport и дождитесь состояния подключения на
   главной. Перезапустите игру или Discord, чтобы новые соединения выбрали маршрут.

Настройки и ключи хранятся в fnport.json рядом с программой. При обновлении
сохраните этот файл и распакуйте новый архив целиком, включая ядро sing-box.
Перед передачей папки другому человеку удалите из копии конфигурацию и подписки.

Подписки поддерживают списки VLESS в тексте/Base64 и подключения sing-box JSON.
Clash YAML и Xray JSON не преобразуются. После загрузки выберите сервер и нажмите
«Применить». Идентификатор устройства сохраняется между обновлениями программы;
совместимость с форматом и ограничениями конкретного поставщика зависит от него.

Для голоса Discord нужен транспорт с поддержкой UDP. HTTP-прокси может открыть
сообщения, но не обеспечить голос. Пинг голосового сервера зависит от маршрута
через ваш VPN; игровой UDP Fortnite при этом остается прямым.

Обычная сборка не содержит запись сетевого следа из разработческих версий.
В игре не меняются код или память процесса, DLL в нее не внедряются.

## OpenWrt

Откройте «Сервисы → fnport → Подключения». Функция выключена по умолчанию и
работает отдельно от игрового fnport и других установленных VPN-служб.

1. Нажмите «Установить компоненты». Нужны доступ к GitHub и не менее 140 МБ
   свободного постоянного места. На роутерах с маленькой flash потребуется
   внешний накопитель с extroot. Обычный игровой обход не требует этих компонентов.
2. Выберите WARP, AmneziaWG/WireGuard или протокол вашего VPN. Для WARP получите
   ключ. Готовую конфигурацию WARP можно импортировать как WireGuard или AmneziaWG:
   оба варианта принимают .conf с одним Peer. VLESS принимает ссылку; остальные подключения принимают
   один объект sing-box. Подписки на роутере пока не загружаются.
3. Выберите сервисы и устройства. MAC-адрес позволяет учитывать DNS-запросы
   устройства по IPv4 и IPv6. Можно указать локальный IPv4-адрес.
4. В дополнительных настройках выберите WAN, сети устройств и DNS: Cloudflare,
   Google или Quad9, с HTTPS, TLS или без шифрования.
5. Включите подключение, сохраните и примените настройки. Дождитесь статуса
   «Подключено», затем перезапустите приложения на выбранном устройстве.

Служба использует отдельное статическое ядро sing-box и собственный TUN для
WARP/WireGuard/AmneziaWG. Конфигурация Forkop/Podkop не изменяется. Если другая
служба принудительно маршрутизирует тот же трафик, ее правила также нужно учитывать.

DNS выбранных сервисов идет через выбранное подключение. Остальные имена
передаются существующему DNS роутера. Внешний DNS over HTTPS внутри приложения
обходит этот DNS-механизм; для таких случаев доменная маршрутизация может быть
неполной. Ранее закешированные ответы тоже могут потребовать перезапуска приложения.

Маршрутизация сервисов пока IPv4. Для выбранных доменов служба не возвращает AAAA;
это не выключает IPv6 во всей сети. Игровые UDP-порты 9000-9999 и 15000-15999
исключены из маршрутизации через подключение. Адресные диапазоны Discord из
itdoginfo применяются только к голосовому UDP на портах 50000-65535, не ко всему TCP.

Ключ WARP находится в /etc/fnport/connections/warp.json, настройки и импортированный
профиль в /etc/config/fnport_connections. Доступ к ним только у администратора.
В статусе отображаются состояние, точка выхода Cloudflare и внешний адрес,
без ключей и содержимого профиля.

## WARP и диагностика

WARP проверяет наблюдаемую точку выхода Cloudflare: Латвия, Польша, Эстония,
Финляндия и Швеция в приоритете; Германия запасная. Из проверенных подходящих
выходов выбирается кандидат с меньшей измеренной задержкой. Cloudflare anycast
не гарантирует доступность конкретной страны. При отсутствии рабочего разрешенного
выхода подключение сообщает об ошибке.

Перед выбором проверяется загрузка 1 МиБ. Это отсекает соединение, которое
отвечает только на первые пакеты, но не гарантирует постоянную скорость.
Геолокация адреса в 2ip может показывать Россию при зарубежной точке Cloudflare:
поля colo и loc описывают разные вещи.

Проверка провайдера использует маяки Epic. Она сначала проверяет текущий TTL
и не предлагает снижать его по смешанным ответам. Рекомендация другого значения
требует двух полных серий и применяется только по кнопке. Успешная проба не гарантирует вход
на конкретный игровой сервер. Сохраняйте журнал и время неудачного перехода;
при повторяемом возврате в лобби полезен также FortniteGame.log за тот же запуск.
