### Добавлено

- Единая вкладка «Подключения» для WARP и своего VPN. Через нее можно направить сервисы Epic, Discord и выбранные приложения. Игровой UDP Fortnite остается прямым.
- Импорт AmneziaWG из файла .conf, VLESS-ссылок и подписок. Выбранный сервер сохраняется между запусками.
- Подключения WARP и своих VPN для выбранных устройств в LuCI. Это дополнительная функция, обычный игровой обход работает отдельно.

### Исправлено

- Выбор исходящих портов при одновременных игровых соединениях и порядок отправки первых пакетов.
- «Проверка провайдера» сохраняет текущий TTL при неоднозначных ответах. Рекомендации применяются только по кнопке, запасные фейки проверяются автоматически.
- Перед выбором выхода WARP проверяется загрузка данных. В приоритетные страны добавлена Швеция.
- Прокрутка настроек, выпадающие списки, выбор приложений и расположение переключателей.
- Добавлена пропущенная сеть игровых серверов AWS в Париже. Старый стандартный список Windows обновляется автоматически.

**Windows:** скачайте [fnport-windows-v0.7.0.zip](https://github.com/YUNGSLXRD/fnport/releases/download/v0.7.0/fnport-windows-v0.7.0.zip), закройте программу и распакуйте архив поверх старой папки. Настройки и ключ WARP сохранятся.

**Роутер:** обновление через кнопку «Обновить» в LuCI или [установщик из README](https://github.com/YUNGSLXRD/fnport#readme). Выбирать архитектуру вручную не нужно.

[Пакеты для ручной установки OpenWrt и контрольные суммы](https://github.com/YUNGSLXRD/fnport/releases/tag/components-v0.7.0). Компоненты роутера установщик скачивает сам. Если уже установили раннюю сборку 0.7.0, повторите команду установщика из README перед установкой компонентов подключений.
