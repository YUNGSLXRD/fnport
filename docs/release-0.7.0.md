В Windows появилась единая вкладка «Подключения»: WARP, свой VPN, сервисы Epic,
Discord, импорт AmneziaWG .conf и подписок VLESS/sing-box. Игровой UDP Fortnite
продолжает идти напрямую через fnport.

Исправлены столкновение исходящих портов при одновременных игровых соединениях
и порядок отправки накопленных первых пакетов. Проверка провайдера осторожнее
оценивает неоднозначные ответы и сохраняет текущий TTL при смешанных результатах.
Скрытое снижение TTL после проверки убрано, ее рекомендации применяются только по кнопке.
WARP проверяет загрузку перед выбором выхода.

В LuCI добавлены подключения для выбранных устройств: WARP, свои VPN и Discord,
импорт .conf, выбор DNS over HTTPS/TLS или обычного DNS. Функция выключена по
умолчанию; дополнительные компоненты устанавливаются отдельно по кнопке и требуют
не менее 140 МБ свободного места. Обновлена проверка провайдера на OpenWrt.

Подключения сервисов пока работают по IPv4. Успех на маяке не гарантирует вход
в каждый матч. Причины всех возвратов STW в лобби не объявляются исправленными.
Подробности: [настройка подключений](https://github.com/YUNGSLXRD/fnport/blob/v0.7.0/docs/connections.md). Сетевой след из дев-сборок в релиз не входит.

Добавлена сеть игровых серверов AWS в Париже `51.44.0.0/16`. Прежний стандартный список Windows обновляется автоматически; пользовательские списки сетей сохраняются.
