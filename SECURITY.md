# Безопасность

Исправления безопасности выпускаются для последней стабильной версии fnport.
Перед проверкой убедитесь, что используете актуальную сборку.

## Как сообщить об уязвимости

Не публикуйте действующие ключи, пароли и подробности еще не исправленной уязвимости
в обычном issue. Используйте [приватное сообщение об уязвимости](https://github.com/YUNGSLXRD/fnport/security/advisories/new)
на вкладке **Security**, пункт **Report a vulnerability**.

Опишите затронутую версию, необходимые условия, шаги воспроизведения и возможное
влияние. Пример конфигурации должен содержать вымышленные значения вместо реальных
ключей и подписок. Если секрет уже оказался в публичном доступе, отзовите или замените его.

Не проверяйте уязвимости на чужих устройствах, аккаунтах и сетях без разрешения.
Не публикуйте персональные данные других пользователей.

Обычные ошибки подключения, результаты проверки провайдера и предложения по
интерфейсу относятся к [issues](https://github.com/YUNGSLXRD/fnport/issues).
Срок ответа и выпуска исправления заранее не гарантируется.

## Проверка загрузок

Официальные сборки размещены в [релизах этого репозитория](https://github.com/YUNGSLXRD/fnport/releases).
Для исполняемых файлов доступны подтверждения сборки GitHub Actions. Проверка:

```sh
gh attestation verify fnport.exe -R YUNGSLXRD/fnport
```

Контрольные суммы находятся в соответствующем служебном выпуске компонентов,
ссылка на него приведена в описании основного релиза.
