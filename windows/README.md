# fnport для Windows (в работе)

Задумка: fnport без роутера с OpenWrt, программой на самом игровом ПК. Игра шлёт пакеты к серверам AWS
в Европе через виртуальный адаптер [Wintun](https://www.wintun.net/), программа отправляет их дальше
со своего порта, выбранного проверкой, с фейком перед первым пакетом, и возвращает ответы. Драйвер
WinDivert, который выгружает Easy Anti-Cheat, не нужен.

Работает, только если роутер дома не меняет исходящий порт. Обычно так и есть, но это надо проверять.

## Пробник `fnport-probe`

Перед программой проверяем на ПК, получится ли:

1. сохраняет ли роутер исходящий порт (STUN);
2. есть ли заморозка у провайдера (маяки Epic, UDP 22222) и снимает ли её фейк, отправленный с ПК,
   с каким TTL;
3. работает ли путь через адаптер Wintun и сколько он добавляет к пингу.

Запуск: распаковать архив, двойной щелчок по `fnport-probe.exe`, разрешить запуск от администратора
(нужен для адаптера). VPN и WARP на ПК перед проверкой выключить, игру закрыть. Проверка идёт 2–4 минуты,
отчёт сохраняется рядом с программой (`fnport-probe-<дата>.txt`), адресов ПК и внешнего адреса в нём нет.
Адаптер `fnport-probe` удаляется в конце проверки.

## Программа `fnport`

Окно с боковой панелью и значок в трее, тёмная и светлая темы (или как в Windows), шрифт Inter. Права администратора программа просит сама (они нужны для адаптера).

- **Главная**: круглая кнопка включения, пинг до маяков Epic во Франкфурте, Лондоне и Париже (зелёный —
  отвечают, жёлтый — пинг от 100 мс, красный — нет ответа; пингуются каждые 5 с, только пока окно открыто,
  «Проверить» — сразу), счётчики соединений, проверенных портов, заморозок и переводов на новый порт.
- **Сводка**: по городам — матчи, соединения, сколько прошло без проблем, сколько спасено переводом на новый
  порт и сколько не удалось; ниже игровые серверы этого запуска — адрес, город, порт игры и порт, с которого
  fnport шлёт серверу, пакеты, состояние.
- **Журнал**: то же, что в `fnport.log` рядом с программой.
- **Настройки**: проверка провайдера (сохраняет ли роутер порт, есть ли заморозка, какие фейк и TTL подходят;
  «Применить» ставит рекомендацию; «Скопировать отчёт» — текст для issue по шаблону «Отчёт о провайдере»,
  серверы в нём показаны городами, остальные адреса скрыты), тема, сетевой адаптер, фейк и его TTL, сети и порты, параметры проверок.
  Всё хранится в `fnport.json` рядом с программой.

Фейки лежат в папке `fakes` рядом с программой: туда можно положить свои `.bin` (не больше 1500 байт), выбранный
в настройках — основной, остальные — запасные. Если папки нет, программа создаёт её со своими фейками.

Крестик закрывает окно совсем (видеопамять освобождается), программа остаётся в трее и показывает
уведомление. Значок в трее — буквы FP с точкой: серая — выключено, зелёная — работает, жёлтая — недавно
были заморозки. Щелчок — открыть окно, правый щелчок — меню. Вторая копия программы не запускается,
а открывает окно первой.

Когда fnport включён, Windows направляет в адаптер `fnport` трафик к сетям из настроек (по умолчанию AWS
в Европе: `3.0.0.0/8`, `13.32.0.0/11`, `15.0.0.0/8`, `18.0.0.0/8`, `35.156.0.0/14`, `35.176.0.0/13`):

- игровой UDP (порты сервера 9000–9999, 15000–15999) — с порта, прошедшего проверку рукопожатием Unreal,
  с фейком перед первым пакетом; замёрзшее соединение переводится на новый порт, как в fnport на роутере;
- остальной UDP — с любого порта, без проверок;
- TCP — без изменений, через встроенный TCP-стек (gVisor).

Игру программа не трогает: ни внедрения в процесс, ни драйвера перехвата пакетов. Адаптер — Wintun,
как у WireGuard. При выключении или выходе Windows удаляет адаптер вместе с маршрутами.

Если ПК есть в «Устройствах» fnport на роутере, его оттуда нужно убрать (иначе роутер перепроверяет
порты за программой) или включить в настройках «Только пропуск через адаптер».

Окно нарисовано на [Gio](https://gioui.org): кадр рисуется, только когда что-то изменилось или идёт
короткая анимация. Перетаскивание окна не перерисовывает его (Gio иначе рисует кадр на каждый сдвиг, и окно
двигается рывками), колесо мыши прокручивает списки плавно.
Посмотреть вкладки без Windows: `go test -tags preview -run TestPreview ./fnport/` (нужны cgo, EGL и дисплей,
например Xvfb), картинки — в `FNPORT_PREVIEW_DIR`.

## Сборка

Linux или macOS, нужны Go и zip: `./build.sh` → `dist/fnport-<версия>.zip` и `dist/fnport-probe-<версия>.zip`.

## Сторонние файлы

- `wintun.dll` 0.14.1 (x64), подписан WireGuard LLC, без изменений. Взят из Go-модуля
  `github.com/sagernet/sing-tun@v0.9.6` (модуль сверяется с базой контрольных сумм Go, файл — по SHA-256
  в `build.sh`). Распространяется вместе с программой, которая пользуется им только через его API, по
  [лицензии Wintun для готовых сборок](third_party/wintun-LICENSE.txt); она лежит в архиве рядом с DLL.
- Фейки QUIC (`quic_initial_*.bin`) — файлы пакета fnport, см. [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).
- Библиотеки WireGuard для Go (`golang.zx2c4.com/wireguard`, `golang.zx2c4.com/wireguard/windows`) — MIT.
- gVisor (`gvisor.dev/gvisor`, TCP-стек) — Apache 2.0.
- Gio (`gioui.org`, окно) — MIT или Unlicense; шрифт Go Mono (`gofont`) — BSD.
- Шрифт [Inter](https://github.com/rsms/inter) — SIL Open Font License 1.1 (`internal/fonts/OFL.txt`, в архиве
  `font-Inter-OFL.txt`); в программу вшиты начертания Regular и SemiBold, сделанные из вариативного шрифта
  скриптом `internal/fonts/make.sh`.
